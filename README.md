## Run the assignment

1. Install R and RStudio.
2. Open `lab-01.Rmd` in RStudio and install the required packages once:

```r
install.packages(c("rmarkdown", "knitr", "cleanrmd", "tidycensus", "tidyverse"))
```

3. Obtain a free Census API key at https://api.census.gov/data/key_signup.html and activate it using the email instructions. In your own RStudio Console, run:

```r
tidycensus::census_api_key("YOUR_OWN_KEY", install = TRUE)
```

Restart RStudio so it loads your key, then click **Knit**. Do not put your actual key in this repository. An internet connection is needed to retrieve ACS data and external resources.

The document uses its own folder as the working directory. No machine-specific paths or custom CSS file are required. The HTML uses the built-in Almond theme.

## Data sources

- Table selection: https://censusreporter.org/topics/income/
- ACS technical documentation: https://www.census.gov/programs-surveys/acs/technical-documentation.html
- Census API, 2024 ACS five-year estimates: B25075 (housing value), C17002 (income-to-poverty ratio), and B19013 (median household income).

The final exercise compares median household incomes across the 50 states. Its summary statistics describe state medians, not individual households or the national mean household income.
